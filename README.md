# 高考新课标 3000 单词查询

[English](README.en.md) | 简体中文

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](LICENSE)

本地网页：按英文单词或中文释义检索高考新课标词汇。页面打开后即可搜索，也可在同一局域网的手机或其他电脑上打开。

当前词库约 832 个词，由课标常用词与课堂加词合并、去重而成。

## 功能

- 输入英文或中文，实时过滤单词卡片
- 清空搜索框后重新展示全部单词
- HTTP 服务监听 `0.0.0.0:8811`，同一局域网内的其他设备可以访问

## 环境

- Python 3.8 或更高版本
- 无需安装第三方包

## 使用

在项目目录执行：

```bash
python serve.py
```

本机打开：

```text
http://127.0.0.1:8811/
```

服务启动后，终端会打印本机局域网地址，例如：

```text
http://192.168.x.x:8811/
```

把该地址发给同一 Wi-Fi 下的手机或电脑即可。其他设备不要使用 `localhost` 或 `127.0.0.1`。

若其他设备打不开，请检查 Windows 防火墙是否放行 Python，或为本机 `8811` 端口添加入站规则。

## 重新生成页面

`1.txt` 里是原始页面和加词原文。改完后执行：

```bash
python build.py
```

会把加词合并进 `index.html`，界面和搜索逻辑保持不变。

## 项目结构

| 文件 | 说明 |
|------|------|
| `index.html` | 查询页（词库 + 界面） |
| `serve.py` | 局域网 HTTP 服务，端口 8811 |
| `build.py` | 从 `1.txt` 合并词库并生成 `index.html` |
| `1.txt` | 原始 HTML 与课堂加词 |
